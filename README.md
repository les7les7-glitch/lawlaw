# LAW / 175 — 3 Themes Edition

175개 로스쿨 면접 주제 카드 학습 웹앱. 기존 Reader Edition의 사례 답변·판단 기준·근거·반론·심화 내용·꼬리질문·메모·진도·검색·복습·스와이프 기능은 유지하며, **처음 1회 디자인 선택 화면**을 추가했습니다.

## 테마

- **01 Noir:** 차콜/남색 배경과 민트 포인트. 기존 다크 테마를 유지했습니다.
- **02 Notebook:** 따뜻한 아이보리 줄노트 질감과 펜/잉크 느낌. 내용의 글씨 크기와 줄 간격을 유지합니다.
- **04 Glass Dusk:** 저녁빛 남보라 배경, 옅은 종이색 질문 카드, 어두운 반투명 해설 카드.

첫 실행 때 선택 후 **선택한 테마로 시작하기**를 누르세요. 이후 상단 오른쪽 **설정(톱니바퀴) → 읽기 테마**에서 즉시 변경할 수 있습니다. 디자인 선택은 브라우저 `localStorage`의 `law175-visual-theme-v1`에 따로 저장됩니다. 기존 진도·메모는 이전 버전과 동일한 `lawschool175-sprint-2026-v1` 키를 유지합니다.

## 단일 파일로 사용

`law175-three-themes.html` 하나만 다운로드하면 175개 학습 데이터와 스타일, 기능이 모두 포함되어 있습니다. 원본 PDF나 인터넷에서 불러오는 학습 데이터가 필요하지 않습니다. 단, **아이폰 파일 앱의 HTML 미리보기에서는 JavaScript/저장 동작이 제한될 수 있습니다.** 안정적인 Safari 앱 경험은 정적 호스팅한 URL에서 얻을 수 있습니다.

## GitHub Pages에 올리기

1. 이 ZIP을 **압축 해제**합니다.
2. `index.html`, `app.js`, `topics.js`, `styles.css`, `themes.css`, `manifest.webmanifest`, `sw.js`, `icon-*.png`, `.nojekyll` 등 **압축 푼 내부 파일들**을 저장소 최상위에 업로드합니다.
3. GitHub에서 **Settings → Pages → Deploy from a branch → main / (root)**를 지정합니다.
4. 배포 주소를 Safari에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 사용할 수 있습니다.

**주의:** 일반적인 개인 GitHub Pages 웹사이트는 공개 접근입니다. 저장소가 private이라는 사실만으로 배포된 사이트가 비공개가 되지 않습니다. 교재 관련 내용이 들어 있는 앱을 본인과 친구들만 비공개로 쓰려면 접근 제한이 가능한 호스팅을 이용하거나 HTML 파일을 각자 공유하세요.

## 조작법

- 앞면 카드 터치: 답변 보기
- 뒷면 카드 터치: 질문으로 되돌아가기
- 좌/우 스와이프: 다음/이전 주제
- 심화 내용 보기 / 꼬리질문·답변 보기: 별도 펼치기
- 모름/애매함/익힘: 이해도 저장 후 다음 주제로 이동
- 메모, 즐겨찾기, 목차 검색, 취약 복습, 현황 확인, JSON 백업 및 가져오기 지원

## 저장 및 출처

학습 진도와 선택한 테마는 기기·브라우저별로 저장되며 자동 동기화되지 않습니다. **기기 간 기록 이동 시 설정의 JSON 백업/가져오기**를 사용하세요. 원본 책 PDF는 포함되지 않습니다. 교재의 001~175 주제명 및 해당 목차 위치를 바탕으로 구성했으며, 질문·사례·사례별 답변·심화·꼬리질문 해설은 학습용으로 별도 작성한 내용입니다. 저자의 공식 모범답안이나 최신 판례의 검증본이 아닙니다.
