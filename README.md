# LAW / 175 — Reader Edition

로스쿨 면접 175개 주제를 모바일 **카드뉴스처럼 스와이프**하며 학습하는 정적 웹앱입니다. React 설치나 빌드가 필요 없습니다.

## GitHub Pages에 올리기

1. GitHub에서 새 **Public** 저장소(예: `law175`)를 생성합니다.
2. 이 폴더의 **파일들을 모두** 저장소의 최상위 디렉터리에 업로드합니다. (ZIP을 그대로 올리면 안 됩니다.)
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. 브랜치 `main`, 디렉터리 `/(root)`를 선택하고 Save 합니다.
5. 배포가 완료되면 `https://본인아이디.github.io/law175/` 형식의 주소로 접속할 수 있습니다. 저장소 이름은 주소에 영향을 줍니다.

## 아이폰 홈 화면에 추가하기

1. 아이폰에서 위 배포 주소를 **Safari**로 엽니다.
2. 공유 아이콘을 누르고 **홈 화면에 추가**를 선택합니다.
3. 홈 화면의 LAW 175 아이콘을 통해 다시 열 수 있습니다.

## 터치 조작

- **카드 한 번 터치**: 핵심 해설 공개
- **카드 왼쪽으로 밀기**: 다음 주제
- **카드 오른쪽으로 밀기**: 이전 주제
- **심화 내용 보기 / 꼬리질문 답변 보기**: 개별 펼침
- **모름 / 애매함 / 익힘**: 이해도 저장 후 다음 카드
- **하단 목차**: 번호, 주제명 검색 및 필터
- **하단 복습**: 모름·애매함으로 표시한 주제만 보기
- **상단 별**: 즐겨찾기
- **설정 → JSON 백업/복원**: 학습 기록 보관

## 데이터 및 호환성

- 기존 LAW 175 앱과 동일한 `localStorage` 키 `lawschool175-sprint-2026-v1`를 사용합니다. **같은 도메인/브라우저**에서 배포한 구버전은 진도를 이어 쓸 수 있습니다.
- 파일로 실행한 버전, GitHub Pages 버전, Safari 홈 화면에 추가한 버전은 **서로 다른 저장공간**을 가질 수 있습니다. 설정에서 **JSON으로 내보내기/가져오기**를 이용해 기록을 옮겨 주세요.
- 별도 서버·로그인이 없고, 학습 진도는 브라우저에만 저장됩니다. 기기 간 자동 동기화는 지원하지 않습니다.
- 원본 교재 PDF는 포함하지 않습니다. 1권(001~095), 2권(096~175)의 **주제명과 시작 쪽수**를 교재 목차를 기준으로 정리했고, 개별 질문·핵심·심화·꼬리질문 답변은 **AI가 별도로 작성한 학습용 해설**입니다. 교재 저자의 모범답안 또는 실제 법령·판례에 대한 최신 검증본이 아닙니다.

## 구조

- `index.html` — 화면 구조, 앱 설치 메타정보
- `styles.css` — 모바일/데스크톱 반응형 다크 테마
- `topics.js` — 175개 학습 카드 데이터
- `app.js` — 카드 스와이프, 평가, 복습, 검색, 저장/백업
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — 홈 화면 추가 및 오프라인 지원

파일을 변경하면 GitHub Pages가 같은 주소로 새 버전을 배포합니다. 오프라인 캐시가 남아 있는 경우 Safari를 완전히 다시 열거나 한 번 새로고침하세요.

## 구체 사례 카드 추가 (v2)

- 질문 제목 바로 아래 CASE STUDY 작은 카드에 한 주제당 한 가지 **구체적 상황·소문제**를 표시합니다. 총 175개입니다.
- `교재 문항 재구성` 표시는 실제 업로드된 교재 문제를 직접 확인해 상황을 짧게 요약한 경우입니다(001, 003, 009, 096, 115번). 책의 원문 그대로가 아닙니다.
- `추가 연습 사례`는 저자 교재에서 인용한 문제가 아니며 해당 주제에 맞춰 **독립적으로 작성한 가상 사례**입니다.
- 기존 학습 기록 저장 키 및 다른 학습 기능은 변경하지 않았습니다.


## Reader Edition (v3) — 답변 가독성 개선

- **175개 전 주제**에 개별 `사례 답변`과 사례를 반영한 `판단 기준`/`고려할 근거`/`반론과 한계`를 추가했습니다. 이 내용은 저자 모범답안이 아니라 AI가 독립적으로 만든 학습 의견 예시입니다.
- 답변 카드의 어느 빈 곳이나 **터치하면 질문 카드로 복귀**합니다. 가로 스와이프로 주제를 이동합니다.
- 본문 글자는 키우고, 단계 표시·타이머·중복 상자를 없애 심화/꼬리질문 버튼이 답변 아래 바로 표시되게 했습니다.
- 펼친 심화 설명이나 꼬리질문은 길기 때문에 해당 화면에서 세로 스크롤할 수 있습니다. 작은 스마트폰/긴 사례에서는 펼침 버튼을 보려면 조금 스크롤이 필요할 수 있습니다.
- 학습 메모와 진도는 기존 `lawschool175-sprint-2026-v1` 저장소 키를 사용합니다. 주소가 다르면 JSON으로 옮겨야 합니다.
